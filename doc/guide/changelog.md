# 更新日志

FkeMark 的正式发布记录以 GitHub Releases 为准。文档站在头部提供“版本”下拉，用来跳转历史版本和当前更新日志入口。

## 快速入口

- [历史版本](https://github.com/fantasy-ke/FkeMark/releases)：查看所有已发布版本与安装包。
- [最新发行版](https://github.com/fantasy-ke/FkeMark/releases/latest)：直接进入当前最新版本页面。

## 阅读建议

| 入口 | 适合场景 |
| --- | --- |
| 历史版本 | 对比不同版本、下载旧版本安装包 |
| 最新发行版 | 下载当前稳定包、查看最新变更说明 |
| 文档教程 | 了解功能用法、部署方式和主题配置 |

## 文档站维护记录

当前文档站已经完成：

- 切换到 VitePress Theme Teek。
- 统一首页、文档页、侧边栏和顶部导航配色。
- 新增中文 / English 双语文档入口。
- 新增“功能模块与按钮”页面，覆盖版本历史、差异导航、片段、拼写检查、演示模式和相关设置。
- 新增头部“版本”下拉，连接历史版本与更新日志。
- 新增“实时渲染兼容性”页面，说明 BlockNote 实时编辑、代码高亮、图片 / 表格右键菜单和列表换行的当前支持范围。
- 更新编辑教程与 Markdown 语法页，补充代码块语言高亮、图片 / 表格右键操作和紧凑列表写法。
- 补充近期应用功能说明：本地订阅与 7 天试用入口、主题卡片选择、订阅布局优化、头部菜单关闭态、设置页搜索与布局密度优化，以及仅开发版可见的 DevTools 访问策略。

后续如果项目新增独立 <code>CHANGELOG.md</code>，可以把本页改为按版本整理的更新记录，并继续保留 GitHub Releases 作为安装包下载入口。
