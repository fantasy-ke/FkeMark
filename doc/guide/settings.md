# 设置页面

设置页面用于统一调整外观、编辑体验、视图、行为、图片、语言、快捷键、AI 辅助和实验选项，也包含工具栏布局、行号显示和版本快照保留数量等新增项。

![FkeMark 设置页面](/images/guide/settings.svg)

## 设置分区

| 分区 | 可调整内容 | 推荐使用场景 |
| --- | --- | --- |
| 外观 | 主题、字体、字号、行高、圆角 | 让阅读和写作更舒服 |
| 编辑器 | 默认编辑模式、标记显示、自动括号、拼写检查 | 调整日常输入体验 |
| 视图 | 编辑宽度、显示行号、小地图、专注模式、工具栏位置 | 适配长文、宽屏或小屏 |
| 行为 | 自动保存、关闭窗口动作、版本快照保留数量 | 避免误关、丢失内容或快照过多 |
| 图片 | 图片保存、上传或资源处理相关选项 | 统一 Markdown 图片管理方式 |
| 语言 | 中文 / English | 切换界面语言 |
| 快捷键 | 应用和编辑器快捷键 | 建立自己的高频操作习惯 |
| AI 辅助 | 本地或 OpenAI-compatible API 配置 | 续写、润色、摘要、翻译等辅助写作 |
| 实验选项 | Mermaid、Vim 等增强能力 | 按需开启，不影响基础写作 |
| 关于 | 版本、更新通道、开发工具入口 | 检查版本或更新 |

## 重点设置

| 设置 | 推荐理解 |
| --- | --- |
| 工具栏布局 | 在“外观”分区拖拽按钮、隐藏低频入口、移动分隔线，或者把按钮收进分组。 |
| 显示行号 | 在“视图”分区开启后，编辑器左侧会显示行号；长文实时编辑时行号会继续增长。 |
| 版本快照保留数量 | 在“行为”分区选择每个文件最多保留 10、25、50 或 100 次本地版本快照。 |
| 拼写检查 | 在“编辑器”分区开启后，工具栏的拼写检查按钮会提供本地写作质量面板。 |

## MCP 执行权限

AI 设置中的 MCP 执行权限用于给所有 MCP 客户端设置统一上限。客户端自己的读写配置、连接只读标记、生产库保护和数据库账号权限仍会继续生效，不能突破这里选择的级别。

| 模式 | 适合场景 | 允许 | 阻止 |
| --- | --- | --- | --- |
| 只读 | 生产库查询、审计报表、知识库问答 | 查询和读取 | 写入、删除、DDL、连接添加/删除 |
| 数据读写（推荐） | 开发库、测试库、明确范围内的数据修正 | 普通 <code>INSERT</code>、带有效条件的 <code>UPDATE/DELETE</code>、MongoDB 范围可验证变更、Redis 明确键写入/删除、MCP 连接添加/删除 | 全表更新/删除、清空数据、DDL 和高风险管理命令 |
| 完全访问 | 本地沙盒、临时环境初始化、短时管理员维护 | 查询、写入、清空数据、DDL、高风险管理命令和连接管理 | 仅受连接范围、账号权限和生产库保护约束 |

### 配置案例

- **生产资料查询**：选择“只读”，MCP 连接使用只读数据库账号，仅开放 <code>SELECT</code>、<code>FIND</code>、<code>GET</code> 等读取工具，适合让 AI 帮忙查资料或生成报表。
- **日常开发维护**：选择“数据读写（推荐）”，允许新增记录、带条件修改和明确键操作，同时阻止全表清空、无条件删除和结构变更。
- **本地沙盒初始化**：选择“完全访问”，只在非生产环境或短时维护窗口开启，用于建表、重建测试数据或清理临时连接；结束后建议切回“数据读写”或“只读”。

## 建议配置

### 长文写作

- 编辑宽度：中等或宽。
- 专注模式：开启。
- 小地图：长文或代码较多时开启。
- 显示行号：需要定位修改位置时开启。
- 版本快照保留数量：建议 50；频繁修改长文时可选 100。
- 自动保存：保持开启。

### 项目文档

- 默认模式：Live。
- 显示 Markdown 标记：开启，便于检查语法。
- 工具栏：固定在顶部或靠近编辑区。
- 快捷键：保留保存、查找、链接、标题等高频项。

### 演示和校对

- 使用 Read 模式检查成稿效果。
- 使用演示模式前，用独立 <code>---</code> 分隔每页幻灯片。
- 需要中英文混写时，保持拼写检查开启。

## 常见问题

### 设置会影响 Markdown 文件内容吗？

不会。多数设置只影响 FkeMark 的显示和编辑体验，不会改写你的 Markdown 文件。

### 快捷键改错了怎么办？

到“快捷键”分区点击单项恢复，或使用“全部恢复默认”。

### AI 辅助是否必须配置？

不是。AI 辅助默认关闭；不开启时不影响本地 Markdown 编辑流程。
