# 更新中心设计

更新弹窗参考 DBX 的布局，分为 FkeMark、文档转换组件和更新日志，显示可用更新数、版本、说明、历史发布入口和各自的下载操作。使用 FkeMark 的主题和现有 GitHub 发布源，保留主程序正式版／开发版通道。

只改弹窗无法报告组件版本；另建组件安装流程会重复校验及进度处理。更新中心复用既有应用下载和组件安装命令，后端单独提供只读组件检查。自动检查只查询已安装组件；未安装的组件仍从组件设置按需下载。

忽略以版本为单位，仅取消该版本提醒，可手动恢复。「更新全部」启动可用下载，组件安装无需重启，主程序仍须用户确认安装并经过原有的文档保存保护。不新增更新源或绕开完整性校验。
