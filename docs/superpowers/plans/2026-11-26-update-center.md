# 更新中心实施计划

**目标：** 将主程序和已安装的转换组件更新统一到一个弹窗。

**设计：** `docs/superpowers/specs/2026-11-26-update-center-design.md`。客户端继续使用 React、Tauri 和现有 CSS 主题；版本发现和组件安装继续由 Rust 执行。

1. 拆分组件查询和安装 → 用定向 Rust 测试验证只读比较、旧版兼容和指定版本选择；未安装时不联网查询。
2. 接入自动提醒和更新中心 → 用 Vitest 验证仅组件有更新也可提醒、忽略只影响指定版本、两个来源互不掩盖，以及批量下载不自动重启。
3. 验证界面和集成 → 运行前端测试、生产构建与 Rust 验证，实测正常及窄窗口下的标签切换、可滚动内容和稳定的操作区。
