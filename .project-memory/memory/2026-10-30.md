## 修复 Mermaid 流程图在亮色主题下看不清

- 需求：亮色主题下流程图对比度不足，节点和连线都偏浅；节点之间的连线需要更清楚。
- 实现：
  - 排查确认 Mermaid 使用的 `neutral` 主题在亮色下把节点边框设为 `#999`、连线设为 `#666`，且 `strokeWidth` 默认为 1；流程图实际按 `classic` look 渲染，节点和连线的描边宽度都取自这个值，所以整体偏细偏浅。
  - 把 Mermaid 初始化配置抽成可测试的 `mermaidConfig(dark)`，亮色模式显式传入 `themeVariables`：节点填充 `#f1f5f9`、节点边框 `#475569`、连线 `#334155`、文字 `#0f172a`、箭头 `#334155`，并把 `strokeWidth` 提到 2。暗色模式仍用内置 `dark` 主题，不覆盖主题变量。
- 涉及文件或模块：`src/utils/markdown/mermaid.ts`、`tests/mermaid.diagram.test.ts`。
- 验证结果：
  - 用 jsdom 实际渲染 Mermaid 生成的 SVG 样式表确认：亮色下 `.node rect` 等为 `stroke:#475569;stroke-width:2px`，`.edgePaths .path` 为 `stroke:#334155;stroke-width:2px`，`.marker`/`.arrowheadPath` 为 `#334155`。
  - Chrome headless 并排渲染修复前后并统计像素：修复前节点边框主要落在 `#CCCCCC/#999999`，修复后为 `#475569`（1900 px）且连线为 `#334155`（377 px），肉眼可辨。
  - `npm test` 78 个文件、565 个用例通过；`npm run build` 通过；`git diff --check` 通过。
- 已知限制：主题变量只按亮/暗两档区分，不跟随调色板主题的 CSS 变量；渲染缓存键也只含 `dark`，因此在两个亮色调色板之间切换不会立即重绘（本次未改变该既有行为）。
- Git 提交信息：`fix: 提高 Mermaid 亮色主题流程图对比度`

## 修复 SVG id 重写破坏 Mermaid 内嵌样式表

- 需求：亮色主题下流程图节点变成纯黑方块、节点文字与背景同色看不见，连线渲染成大块黑色楔形。
- 根因：`rewriteSvgIds` 为了避免同页多张图共用 marker/渐变 id，会把 SVG 里所有 `id="..."` 改名；Mermaid 11 的内嵌 `<style>` 用 `#<根 svg id>` 限定作用域，而该函数没有同步样式表里的 `#id` 选择器。改名后整张图的主题 CSS 全部失效，节点回落到 SVG 默认黑色填充，文字继承外层 `--fg` 变深色，连线 `<path>` 用默认黑色填充而非描边，于是出现黑色楔形。
- 实现：`rewriteSvgIds` 在改写 `id`、`url(#...)`、`href="#..."` 之后，再对每个 `<style>` 块把 `#<旧 id>` 同步替换成 `#<新 id>`；替换时用 `(?![\w-])` 边界避免误改 `#id-xxx` 这类已被 `url()` 规则处理过的引用，也避免影响节点文字里的 `#` 内容。
- 涉及文件或模块：`src/utils/markdown/heavyRender.ts`、`tests/render.cache.test.ts`。
- 验证结果：
  - Chrome headless 加载应用真实 CSS，对比同一段 Mermaid SVG 直接插入与经过 `rewriteSvgIds` 后的计算样式：修复前 `.node rect` 计算值为 `fill: rgb(0,0,0)`、`stroke: none`、连线 `stroke: none`；修复后与原始 SVG 完全一致（`fill: rgb(241,245,249)`、`stroke: rgb(71,85,105)`、连线 `rgb(51,65,85)`、`2px`）。
  - 截图复现了用户看到的黑块节点与黑色楔形连线，修复后恢复为正常浅色节点和清晰连线。
  - `npm test` 78 个文件、566 个用例通过；`npm run build` 通过。
- 已知限制：`aria-labelledby` / `aria-describedby` 指向的 `<title>`、`<desc>` id 仍不会随改名同步，属于既有问题，本次未处理。
- Git 提交信息：`fix: 修复 SVG id 重写导致 Mermaid 样式失效`
