## 修复 Mermaid 流程图在亮色主题下看不清

- 需求：亮色主题下流程图对比度不足，节点和连线都偏浅；节点之间的连线需要更清楚。
- 实现：
  - 排查确认 Mermaid 使用的 `neutral` 主题在亮色下把节点边框设为 `#999`、连线设为 `#666`，且 `strokeWidth` 默认为 1；流程图实际按 `classic` look 渲染，节点和连线的描边宽度都取自这个值，所以整体偏细偏浅。
  - 把 Mermaid 初始化配置抽成可测试的 `mermaidConfig(dark)`，亮色模式显式传入 `themeVariables`：节点填充 `#f1f5f9`、节点边框 `#475569`、连线 `#334155`、文字 `#0f172a`、箭头 `#334155`，并把 `strokeWidth` 提到 2。暗色模式仍用内置 `dark` 主题，不覆盖主题变量。
- 涉及文件或模块：`src/utils/markdown/mermaid.ts`、`tests/mermaid.diagram.test.ts`。
- 验证结果：
  - 用 jsdom 实际渲染 Mermaid 生成的 SVG 样式表确认：亮色下 `.node rect` 等为 `stroke:#475569;stroke-width:2px`，`.edgePaths .path` 为 `stroke:#334155;stroke-width:2px`，`.marker`/`.arrowheadPath` 为 `#334155`。
  - Chrome headless 并排渲染修复前后并统计像素：修复前节点边框主要落在 `#CCCCCC/#999999`，修复后为 `#475569`（1900 px）且连线为 `#334155`（377 px），肉眼可辨。
  - `npm test` 78 个文件、565 个用例通过；`npm run build` 通过；`git diff --check` 通过。
- 已知限制：主题变量只按亮/暗两档区分，不跟随调色板主题的 CSS 变量；渲染缓存键也只含 `dark`，因此在两个亮色调色板之间切换不会立即重绘（本次未改变该既有行为）。
