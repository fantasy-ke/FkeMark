## MCP npm 工作流发布开关修正

- 需求：用户手动触发 MCP npm 工作流时，如果没有明确配置发布，应只上传 tarball artifact，不执行 `npm publish`。
- 实现：为 `.github/workflows/npm-mcp.yml` 增加 `workflow_dispatch.inputs.publish`，默认 `false`；新增 `Resolve publish mode` 步骤，只有 `v*` 标签或手动勾选发布且存在 `NPM_TOKEN` 时才允许发布。
- 涉及文件：`.github/workflows/npm-mcp.yml`、`tests/mcp.package.test.ts`、`packages/fkemark-mcp-server/README.md`。

- 已知限制：如果手动勾选发布或推送 `v*` 标签且配置了无效/权限不足的 `NPM_TOKEN`，npm 注册表仍会返回发布错误，需要更换有效 token 或取消发布。
