- 已知限制或未处理的无关问题：无效或没有发布权限的 `NPM_TOKEN` 仍不能把包发到 npm。`fkemark-mcp-server` 目前在注册表返回 404。需要更换具备发布权限的 token 后重跑工作流，包才会真正发布。

## 延迟渲染公式、流程图和白板预览

- 需求：让公式、流程图和其他重元素渲染更快，并能撑住更大的文档。
- 实现：
  - 抽出 KaTeX、Mermaid、Excalidraw 的 LRU 缓存。编辑和预览的公式改为 `output: 'html'`，同一公式不重复排版。
  - 实时块和分栏预览只在靠近视口时绘制重元素。Mermaid 同时只布局一张，命中缓存后重写 SVG id，避免同页箭头标记串用。
  - 导出和演示仍强制渲染全部公式，用字符串替换代替整篇 `DOMParser`。分栏预览保持占位，插入 DOM 后再水合。
  - 大文档预览对直接子块使用 `content-visibility`。实时编辑只跳过公式、图表和代码内容，不跳过 ProseMirror 要测量的块外壳。
  - 性能敏感文档的小地图改用抽样源码色条，悬停预览按帧节流。
- 涉及文件或模块：`src/utils/markdown/katexRender.ts`、`renderCache.ts`、`heavyRender.ts`、`mermaid.ts`、`excalidraw.ts`、`engine.ts`，`src/components/editor/mathSpecs.ts`、`mermaidBlockView.ts`、`useMermaidDiagrams.ts`、`usePreviewMath.ts`、`Minimap.tsx`，`src/styles/overlays.css`，`tests/render.cache.test.ts`，`docs/方案设计.md`。
- 验证结果：`npm test` 78 个文件、561 个用例通过；`npm run build` 通过；`git diff --check` 通过。
- 已知限制：导出 HTML/PDF 仍不水合 Mermaid 和 Excalidraw，因为这两类渲染不是同步字符串。预览按标题分段缓存和视口外跳过 Shiki 留到下一期。没有做桌面窗口滚动核验。
- Git 提交信息：`perf: 延迟渲染公式和图表`
