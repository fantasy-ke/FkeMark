## 更新前保存与浏览器关闭标签收尾加固

- 需求：保护更新安装前的陈旧路径/内容和未命名脏文档，并修复浏览器环境关闭已有路径文件时错误调用 Tauri 写盘的问题。
- 实现：更新前保存请求继续绑定 `tabId`、路径、内容和修订号；队列执行前后发现路径、内容或修订号失效时返回 `false` 中止安装，仅在同一内容已被其他请求成功保存时允许继续；无路径的未保存标签直接阻止更新安装。成功保存后通过 `markTabSaved` 同步 TabBar 脏标记。
- 实现：关闭标签保存统一使用快照校验和共享保存队列，写入前后复核标签、路径、内容和修订号；保存失败或陈旧时保留标签并提示错误，异步关闭流程使用最新标签 refs。浏览器环境对已有路径和未命名文件均使用下载流程，保持文件名、缓存和 Tab 状态一致，不调用 `write_file_command`。
