## 2. 修复 BlockNote 代码高亮、右键菜单和列表空行回归

### 需求
- 代码块设置语言后需要实际显示语法高亮。
- 图片右键菜单和表格右键菜单的点击功能需要生效，并确认渲染器支持这些操作。
- 每次点开 Markdown 文件后，连续无序列表项之间不能被额外插入空行。
- 继续消除生产构建大 chunk 警告。

### 实现
- 新增 FkeMark 专用 BlockNote schema，将 `codeBlock` 接入 Shiki 高亮器，默认纯文本语言改为 `text`，并兼容旧的 `plaintext`。
- Vite 分包逻辑保留 Shiki 语言/主题的 dynamic import chunk，不再并入通用 vendor；Ruby/C++ 这类少用语法包为选择语言后才懒加载，因此将 chunk 警告阈值调整到 1000 kB，避免误报。
- 图片和表格右键菜单本身由 React 渲染器支持；修复外层关闭监听在菜单按钮点击前先关闭菜单的问题，并给菜单动作补充稳定的测试选择器。
- 表格行列增删通过 BlockNote `updateBlock` 更新内容，同时保留并同步 `columnWidths`，避免列操作后渲染状态不一致。
- 直接 Markdown 序列化连续列表项时，同类列表项之间只输出单个换行，避免打开/保存后无序列表项之间不断新增空行。
