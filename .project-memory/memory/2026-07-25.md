## 1. 修复渲染视图行号定位与空行编号

### 需求
- 修复实时编辑、阅读和分栏预览中，标题等高块渲染后占用多个连续行号、后续行号错位的问题。
- 修复长文档滚动到底前行号已经结束的问题。
- Markdown 空行也必须保留并占用独立行号。

### 实现
- 保留源码视图原有的固定行高单文本节点行号，避免影响源码编辑性能。
- 为渲染视图新增基于实际 DOM 几何位置的行号布局：标题、段落、列表、表格、代码块、分隔线和块级公式按真实顶部位置生成锚点，标题无论视觉高度多大都只对应一个源码行号。
- 将渲染锚点映射回 Markdown 源码行；非空行使用渲染块定位，空行在相邻锚点之间插值或在文档末尾外推，因此空行仍有独立编号。
- 行号容器跟随渲染根节点在滚动区域中的真实偏移，兼容标题外边距折叠；容器高度至少覆盖最终渲染内容和最后一个行号。
- 使用 ResizeObserver、MutationObserver 和 TipTap update 事件重新测量，兼容窗口宽度变化、内容更新及大文档延迟序列化。
- 渲染视图只挂载视口附近的行号，未取得视口尺寸时最多渲染前 200 个标记，避免长文档产生大量 React 节点。
