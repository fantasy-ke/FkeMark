## 清理 TipTap 迁移遗留并补充 README 说明

- 需求：① 清理 BlockNote 迁移后残留的 TipTap 遗留；② 补充 README 的技术栈与项目结构说明。
- 现状核实（需求 ①）：`src/` 与 `tests/` 中共 12 个文件仍写着 `import type { Editor } from '@tiptap/react'`，`package.json` 也仍声明 `@tiptap/core@^2.1.0` 与 `@tiptap/react@^2.1.0`。核实后发现这不只是「没用到的旧依赖」，而是一处**版本错配**：BlockNote 0.46 内部依赖 **`@tiptap/core@3.29.0`**（嵌套在 `node_modules/@blocknote/*/node_modules/@tiptap/` 下），而项目顶层声明的是 v2.27.2，`node_modules` 中因此同时存在两套 TipTap。代码里 `blockNoteEditor._tiptapEditor as unknown as TiptapEditor` 的双重断言把真实的 v3 实例硬转成 v2 类型，掩盖了这处不一致。
- 实现（需求 ①）：
  - 新增 `src/types/editor.ts`，用 `export type TiptapEditor = BlockNoteEditor['_tiptapEditor']` 从 BlockNote 自身类型反推底层编辑器类型。类型因此始终跟随 BlockNote 实际使用的 TipTap 版本，项目不再需要直接声明 `@tiptap/*`。
  - 12 个文件不再从 `@tiptap/react` 取类型：其中 11 个改从 `src/types/editor` 导入，`useBlockNoteEditorController.ts` 因双重断言被删除而不再需要该类型导入。`FindReplaceBar.tsx`、`AiSelectionButton.tsx` 中原本就叫 `Editor` 的类型统一改名为 `TiptapEditor`。
  - `Editor.tsx` 与 `useBlockNoteEditorController.ts` 中的 `as unknown as TiptapEditor` 双重断言随之删除（源类型本身就是该别名）。
  - `package.json` 移除 `@tiptap/core` 与 `@tiptap/react` 两条直接依赖；`npm install` 剪除 16 个包，顶层 `node_modules/@tiptap` 目录消失，只剩 BlockNote 嵌套的 v3。
  - 顺带删除 `src/styles/editor.css` 中的 `.fk-math-edit { display: none; }`——它是已删除的 TipTap `MathNode` 时代的死规则（现行代码只用 `fk-math-editing` 与 `fk-math-edit-ta`，CSS 类选择器按完整词元匹配，不会误伤）。
- 实现（需求 ②）：
  - 技术栈描述由「Tauri + React + ProseMirror」更正为「Tauri v2 + React + BlockNote（基于 ProseMirror / TipTap）」。
  - 特性拆成「编辑体验 / 外观与集成」两组，补上原先未提及的能力：四种视图模式、Mermaid、标题与长代码块折叠、小地图、Wiki 双链与反向链接、文档大纲、命令面板与目录内搜索、全局查找替换、片段模板、拼写检查、Vim 模式、自定义快捷键、本地版本历史、回收站、演示模式、13 套主题、AI 助手、MCP 服务、图床与 WebDAV 同步。
  - 更正两处与实现不符的描述：导出格式由「Markdown / HTML / TXT 互转」改为实际的八种（md/html/txt/pdf/docx/epub/rtf/opml）；删除「打字机模式（光标始终居中）」——该能力只存在于 `Design.md`、`FkeMark-roadmap.md` 与文档站，`src/` 中没有任何实现（`focusMode` 仅隐藏侧栏/工具栏/状态栏）。
  - 项目结构树按实际目录重写，并补「常用命令」表与 `AGENTS.md` 指引。
- 涉及文件或模块：`src/types/editor.ts`（新增）、`src/components/Editor.tsx`、`src/components/FindReplaceBar.tsx`、`src/components/editor/AiSelectionButton.tsx`、`src/components/editor/SnippetsMenu.tsx`、`src/components/editor/useBlockNoteEditorController.ts`、`src/components/editor/useEditorAiAssistant.ts`、`src/components/editor/useEditorPerformanceDiagnostics.ts`、`src/components/editor/useSlashMenuTrigger.ts`、`src/components/editor/useVimMode.ts`、`src/components/editor/useWikiLinkPicker.ts`、`src/styles/editor.css`、`tests/ai.chat.test.tsx`、`tests/snippets.test.tsx`、`package.json`、`package-lock.json`、`README.md`。
