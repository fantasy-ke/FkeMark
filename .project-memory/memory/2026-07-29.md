## 支持 PR 自动代码审查评论

- 需求：保留 `dev` push 的 OpenCodeReview 提交报告，同时在有人提交 PR 时自动审查并向 PR 发送评论。
- 实现：
  - 在 `.github/workflows/code-review.yml` 新增 `pull_request_target` 的 `opened`、`reopened`、`synchronize` 和 `ready_for_review` 触发，草稿 PR 不执行审查。
  - 保留 push 场景的 commit comment，并把 job 权限收敛到 `contents: write`。
  - 新增 PR 审查 job，固定 OpenCodeReview `v1.7.17` 对应的 commit，仅授予 `contents: read` 和 `pull-requests: write`；Action 使用 Git base/head 差异审查，不检出或执行 PR 代码，适配 fork PR 的 AI 评论场景。

  - 增加工作流测试，覆盖 PR 触发、job 条件、最小权限、Action 固定版本、增量评论配置，以及未直接 checkout PR head。
