  - 新增响应式移动运行时 Hook，并同步更新根节点 `mobile-runtime` 类；收敛移动端文件抽屉与 AI 抽屉的互斥开关逻辑。

## 修复 Android fontconfig 交叉编译与发布门禁

- 需求：修复 Android Release 构建因 `yeslogic-fontconfig-sys` 无法使用 `pkg-config` 交叉编译而失败的问题，并处理移动端运行时监听、Release 发布依赖和桌面构建超时的 Medium/High 审查项。
- 根因：`font-kit` 作为全平台依赖被 Cargo 解析到 Android 目标，间接编译仅适用于桌面 Linux 的 `yeslogic-fontconfig-sys`；移动端状态同时使用高频 `resize` 监听；正式发布作业未把 Android 成功作为发布条件。
- 实现：
  - 将 `font-kit` 调整为非 Android 目标依赖；Android 的 `get_system_fonts` 返回空列表，由前端既有逻辑回退到内置字体，避免把桌面 fontconfig 链接链带入 Android。
  - 导出统一的移动端媒体查询，并让根节点样式类和 `useMobileRuntime` 仅监听断点 `change` 事件。
  - 为正式版桌面矩阵构建增加 60 分钟超时；正式发布要求 `build-android` 成功，避免发布缺少 Android 包的不完整 Release。
  - 补充 Android 依赖隔离、媒体查询监听、发布门禁和超时配置的回归断言。
- 涉及模块：`src-tauri/Cargo.toml`、`src-tauri/src/lib.rs`、`src/utils/platform.ts`、`src/main.tsx`、`src/hooks/useMobileRuntime.ts`、`.github/workflows/release.yml`、`tests/mobile.platform.test.ts`。
- 验证：
  - `cargo tree --manifest-path src-tauri/Cargo.toml --locked --target aarch64-linux-android`：依赖树不再包含 `font-kit` 和 `yeslogic-fontconfig-sys`。
  - `npm test`：38 个测试文件、253 项测试全部通过。
  - `npm run build`：通过。
  - `cargo check --manifest-path src-tauri/Cargo.toml`：通过。
  - `cargo test --manifest-path src-tauri/Cargo.toml`：22 项通过。
  - 生产预览在 1280 像素桌面视口正常加载，根节点未误启用 `mobile-runtime`；移动端断点切换由组件测试覆盖。
  - `git diff --check`、定向 `rustfmt --check` 和活跃代码文件 800 行限制检查通过。
- 已知限制：本机仅安装 Windows Rust 目标且未配置 Android SDK/JDK，无法在本地完整产出 APK/AAB；需要由 GitHub Actions 的 Android 环境完成最终打包验证。
