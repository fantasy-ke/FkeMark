## 修复审核报告指出的问题（写入保护、源码选区、WebDAV 同步、浮层定位）

- 需求：按代码审核报告修复 10 处缺陷，涉及批量替换的快照顺序与回滚范围、写入锁毒化、源码模式选区不可见、WebDAV 同步清理丢数据与错误被吞、浮层定位的宽度与上下边界夹紧。
- 实现：
  - `src-tauri/src/file_system/search.rs`：把批量替换的版本快照创建移到写入之前，快照失败即中止本次替换（原为写入后才快照、失败仅告警）；回滚范围改为 `pending[..failed_index]`，只回滚已确认写入成功的文件；`validate_root` 区分「无法访问目录」「不支持通过符号链接搜索目录」「路径不是目录」三种提示。
  - `src-tauri/src/file_system.rs`：写入锁毒化后用 `into_inner()` 继续取用，避免一次写入 panic 导致后续所有保存永久失败。
  - `src/styles/overlays.css`：为 `.source-textarea` 增加半透明 `::selection`，选中内容不再被浏览器默认选区底色遮住（正文颜色由语法覆盖层绘制）。
  - `src/app/useWebdavSync.ts`：effect 清理时先推送仍在防抖窗口内的待发送内容，避免静默丢失；错误提示改为仅在组件卸载时抑制，配置变更不再吞掉真实推送失败；随之移除不再使用的 `generationRef`。
  - `src/utils/popupPosition.ts`：宽度始终以可用宽度为上限（可用宽度为 0 时不再溢出）；`maxHeight` 去掉冗余嵌套并提取 `MIN_POPUP_HEIGHT`；`top` 增加上下边界二次夹紧。
- 涉及文件或模块：`src-tauri/src/file_system.rs`、`src-tauri/src/file_system/search.rs`、`src/styles/overlays.css`、`src/app/useWebdavSync.ts`、`src/utils/popupPosition.ts`；测试 `tests/popup-position.test.ts`、`tests/webdav.sync.test.tsx`、`tests/overlays.style.test.ts`。
- 验证结果：Rust 36 个用例通过，其中新增「替换写入失败时仍会保留替换前快照并回滚已写入文件」，临时改回「先写入后快照」时该用例失败、恢复后通过；4 个新增前端用例在回退源码改动后同样失败，确认可防止回归；完整前端测试 58 个套件、359 个用例通过；`npx tsc --noEmit`、`npm run build`、`git diff --check` 均通过；活跃代码文件均未超过 800 行。
- 已知限制或未处理的无关问题：为保证「替换成功必有快照」，版本历史目录不可写时批量替换会直接失败（原实现仅记录告警后继续替换），属有意的行为变更；配置变更时已在途条目对应的最新待推送内容仍会随清理丢弃，属既有行为，未纳入本次范围。
