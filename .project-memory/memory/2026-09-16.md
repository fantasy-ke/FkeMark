## 优化设置页布局、选项尺寸与下拉适配

- 需求：设置窗口搜索框原先用 sticky 悬浮在内容头部，且因负 top 不满顶；同时需要收紧各组件布局、选项尺寸，并改善下拉框在滚动区域内被裁切、宽度不适配的问题。
- 实现：搜索栏改为右侧内容区顶部固定条，高度与左侧品牌栏对齐，内容区独立滚动；下拉菜单通过 portal 挂到 document.body，按触发器定位、宽度适配长选项，空间不足时向上翻开并夹紧在设置窗口内。
- 涉及文件或模块：`src/components/SettingsPanel.tsx`、`src/components/Select.tsx`、`src/styles/components/settings-page.css`、`src/styles/components/select.css`、`src/utils/popupPosition.ts`、`tests/settings.section-spacing.test.ts`、`tests/popup-position.test.ts`。
- 验证结果：定向前端测试 5 个套件、15 个用例通过；完整前端测试 57 个套件、341 个用例通过；`npm run build` 通过；`git diff --check` 通过；活跃代码文件未超过 800 行。
- 已知限制或未处理的无关问题：AI 设置中的上游格式仍使用原生 `<select>`，本轮未改为自定义 Select；设置页仍可拖动，下拉定位在拖动过程中会随滚动/resize 更新。
- Git 提交信息：`feat: 优化设置页布局与下拉适配`。

## 修复图片上传方式无法切换

- 需求：设置页「图片上传」中的上传方式下拉无法选择更改。
- 实现：自定义 Select 改为在 click 时选中并关闭菜单，mousedown 只阻止默认行为并停止冒泡，避免 portal 到 body 后菜单先卸载、后续 click 穿透设置遮罩；设置遮罩仅在点击背景本身时关闭。
- 涉及文件或模块：`src/components/Select.tsx`、`src/components/SettingsPanel.tsx`、`tests/image.upload.settings.test.tsx`。
- 验证结果：`tests/image.upload.settings.test.tsx` 2 个用例通过；完整前端测试 58 个套件、343 个用例通过；`npm run build` 通过；活跃代码文件未超过 800 行。
- 已知限制或未处理的无关问题：工作区原有未跟踪的 `Temp/` 目录未纳入本次提交；`git diff --check` 因 Windows LF/CRLF 警告产生非空白错误输出。
- Git 提交信息：`fix: 修复设置页图片上传方式无法切换`。
