## 文档嵌入 Excalidraw 手绘白板

- 需求：在 Markdown 文档中嵌入可自由绘制的 Excalidraw 流程图、架构草图和示意图，并保持手绘风格。
- 实现：
  - 文档使用 ` ```excalidraw` 围栏保存 Excalidraw 场景 JSON；实时编辑会把它提升为独立块。
  - 块内提供静态预览、绘制、打开已有 `.excalidraw` 和另存为 `.excalidraw`。绘制器按需加载，不进入首屏。
  - 分栏预览和演示模式把同一围栏水合成静态 SVG；源码模式继续显示原始 JSON。
  - 斜杠菜单和块操作菜单增加插入/转换入口，并补充中英文文案。
- 涉及文件或模块：`src/components/editor/excalidrawBlock.ts`、`src/components/editor/excalidrawBlockView.ts`、`src/components/editor/useExcalidrawDiagrams.ts`、`src/utils/markdown/excalidraw.ts`、`src/utils/markdown/blockNoteSerializer.ts`、`src/components/editor/blockNoteSchema.ts`、`src/components/SlashMenu.tsx`、`src/i18n/locales/`、`src-tauri/capabilities/default.json`、`tests/excalidraw.block.test.ts`。
- 验证结果：
  - `npx vitest run tests/excalidraw.block.test.ts` 4 个用例通过。
  - `npm test` 75 个套件、539 个用例通过。
  - `npx tsc --noEmit` 通过；`npx vite build` 通过，Excalidraw 保持独立懒加载分块。
  - `git diff --check` 通过。
- 已知限制或未处理的无关问题：
  - 打开和另存为只在 Tauri 桌面环境可用；浏览器预览只提供绘制和静态预览。
  - 阅读、分栏和演示使用静态 SVG，不加载完整 Excalidraw 编辑器。
  - 本机无头浏览器核验被临时页面入口和文件锁干扰，没有得到可靠的实机页面结果；功能核验以 jsdom 真实 DOM 测试和构建验证为准。
- Git 提交信息：`feat: 支持文档嵌入 Excalidraw 手绘白板`

## 放大手绘预览并支持独立文件引用

- 需求：默认预览太小；点击绘制后无法使用新增图形等工具，应直接最大化窗口绘制；支持单独新建 `.excalidraw`，再在文章中引用。
- 实现：
  - 文档内预览最小高度改为 420px。
  - 「绘制」不再使用内嵌小画布，而是最大化当前窗口并打开全屏 Excalidraw，完成后写回内嵌 JSON 或引用文件。
  - 文件树显示 `.excalidraw`。文件夹菜单可新建手绘文件；文件菜单可引用到当前文档；斜杠命令也可选择已有文件插入 ` ```excalidraw` 路径引用。点击手绘文件直接打开最大化绘制窗口。
- 涉及文件或模块：`src/components/editor/excalidrawSession.ts`、`src/components/editor/excalidrawBlockView.ts`、`src/components/Sidebar.tsx`、`src/app/useFileTreeActions.ts`、`src-tauri/src/file_system/entries.rs`、`src/utils/markdown/excalidraw.ts`。
- 验证结果：`npm test` 75 个套件、540 个用例通过；`npx tsc --noEmit` 通过；`cargo check --manifest-path src-tauri/Cargo.toml` 通过。
- 已知限制：引用文件的读取和写入只在桌面环境可用；关闭绘制窗口会保存当前场景。
- Git 提交信息：`feat: 放大手绘白板并支持独立文件引用`
