## 引用文件时默认开启 Agent 模式

- 需求：引用文件树中已打开的文件后，AI 回复无法读取本地磁盘。引用文件时应默认走 Agent 模式，而不是普通对话。
- 实现：
  - 点击「引用当前文档」，或发送带文件引用的消息时，自动打开 Agent 模式。
  - 用户消息仍只发送路径标识，不把正文塞进引用本身。
  - Agent 在请求模型前先对当前轮引用调用 `read_markdown`，把读取结果回灌给模型，并提示不要声称无法访问本地文件。
- 涉及文件或模块：`src/components/ai/AiChatSidebar.tsx`、`src/utils/agent/harness.ts`、`src/i18n/locales/ai.ts`、`tests/ai.chat.test.tsx`、`tests/agent.harness.test.ts`。
- 验证结果：
  - `npm test` 75 个套件、541 个用例通过。
  - `npm run build` 通过。
  - `git diff --check` 通过。
  - 活跃代码文件未超过 800 行。
- 已知限制或未处理的无关问题：
  - Agent 读取的是磁盘文件，不包含编辑器里尚未保存的修改。
  - 路径必须位于当前打开的文件夹或 MCP 允许目录内，否则工具会返回「路径不在允许范围内」。
  - 单次读取结果仍按工具上限截断。
- Git 提交信息：`fix: 引用文件时默认开启 Agent 模式`
