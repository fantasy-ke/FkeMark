## 集成 MarkItDown 本地文档与网址导入

- 需求：支持本地其他格式文档及 HTTP(S) URL 转换为 Markdown 后展示；转换器随应用分发，运行用户无需安装 Python；转换不得覆盖原有未保存文档。
- 实现：
  - 新建菜单增加“导入本地文档…”与“从网址导入…”。`useDocumentImport` 复用系统文件选择、`showPrompt`、通知和现有标签管理；成功创建无路径、已修改的新标签，保存仍走原流程。通过最新回调 ref 避免异步导入期间切换或编辑其他标签导致陈旧缓存覆盖。
  - URL 输入弹窗保留确认、取消、Escape 和遮罩防误关，并新增显式关闭按钮。按原有模块合并方式拆分文件/标签/导入导出文案，保留原语言键值，两种主语言文件降到 782 行。
  - Rust 新增 `convert_document`：固定资源路径启动转换器，单次 JSON stdin/stdout 协议，严格结果解析，管道并行有界读取，超时后终止并回收进程。全应用仅允许一个转换任务；输入 50 MiB、输出 Markdown 5 MiB、输入准备 30 秒、进程阶段 90 秒。
  - 本地文件只读复制为临时快照，转换后清理；URL 由现有 reqwest 下载，限制 HTTP(S)、认证信息、私网/回环/保留地址及重定向，固定已校验 DNS 结果，禁环境代理和自动解压，限制实际响应体大小。
  - 使用 MarkItDown 0.1.9 的官方格式转换器，支持 PDF、DOCX、PPTX、XLSX、XLS、HTML/HTM、EPUB、TXT、CSV、JSON、XML。校验实际格式、Office/EPUB 容器与实际解压大小，不允许任意 ZIP、宏或云端转换；HTML 相对链接按最终 URL 解析，Markdown 不额外往返清洗。

## 定时更新检测与居中更新弹窗

- 需求：优化偶尔不提醒的更新流程，定时检查新版本，进入主界面后居中显示更新内容，并提供下载安装和关闭操作。
- 根因：原自动检测未等待设置加载；失败后只能等待下一个 30 分钟周期，没有网络恢复和前台补查；请求及正文读取无超时，可能长期占用检测锁；网络失败会清空已发现版本。原提醒是右下角小通知，内容与下载进度分散在关于页面。
- 实现：
  - `useAppUpdates` 等待 `settingsReady`，启动后延迟 2 秒检查；成功后每 30 分钟检查，失败后 1 分钟重试。网络恢复立即补查；窗口聚焦或重新可见时，补查超过 30 分钟的结果。保留自动检查开关及副窗口隔离。
  - 定时器使用最新检测函数和单个后续任务，重复事件不产生并发网络请求；关闭自动检测后忽略迟到结果。网络失败保留发现的版本；同一运行期间关闭后不重复弹出同版本，手动检查或发现不同版本可重新打开。
  - 更新清单两个通道均添加缓存参数，浏览器请求使用 `no-store`；共享请求函数以 15 秒超时覆盖请求及正文读取，超时取消并继续既有清单/API 降级流程。Tauri HTTP 同时设置连接超时及取消信号。
  - `UpdateDialog` 在主界面且首启引导结束后居中展示版本、发布时间及原始更新说明，内容滚动、操作区常驻；支持关闭按钮、Escape、焦点循环及确认框关闭后的焦点恢复。遮罩不关闭弹窗；兼容浅色、深色、窄窗口与减少动画偏好。
  - 弹窗及关于页面复用 `UpdateActions`，提供下载、进度、暂停、继续、重试、安装确认及外部下载页面。关闭弹窗继续下载；检测中途开始下载后，迟到结果不能替换所选版本。保存保护中止安装时显示原因，可保存文档后再次安装。
