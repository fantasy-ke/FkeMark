## 块操作添加按钮改为插入同语法空块

- 需求：块操作轨道的「添加」按钮此前固定插入空段落，在列表、引用、标题、代码块下方会打断 Markdown 结构；应改为在下方插入一个与当前元素语法相同的空行。
- 实现：
  - `BlockActionRail.tsx` 新增导出 `getSameTypeInsertBlock(block)`：`heading` 返回同级空标题（沿用 `props.level`，缺失时回退 1 级）；`codeBlock` 返回空代码块并保留 `props.language`（缺失时 `text`）；`checkListItem` 返回未勾选空待办；`paragraph` / `quote` / `bulletListItem` / `numberedListItem` 原样返回同类型；`mermaid`、`mathBlock`、`image` 等无行内语法或无法空置的块回退为空段落。
  - 原 `insertParagraph` 改名 `insertSameTypeBlock`，仍保留「插入前展开折叠标题 → 插入后光标落到新块起始并聚焦」的既有行为；插入位置依旧是当前块的 `after`，因此嵌套层级由 BlockNote 自动继承为同级兄弟。
  - 文案同步：`editor.blockActions.add` 中文改为「在下方添加同类型空行」，英文改为 `Add block of same type below`。
- 涉及文件或模块：`src/components/editor/BlockActionRail.tsx`、`src/i18n/locales/zh-CN.ts`、`src/i18n/locales/en.ts`、`tests/block-action-rail.test.tsx`。
- 验证结果：
  - `npx vitest run tests/block-action-rail.test.tsx` 26 个用例通过：新增 `getSameTypeInsertBlock` 的映射与回退断言、空块保存回 Markdown 后仍带同类语法的断言、列表块点击添加按钮插入 `bulletListItem` 的交互断言。
  - `npm test` 73 个套件、526 个用例通过；`npm run build` 通过；`git diff --check` 通过。
  - 界面核验（jsdom 挂载真实 `BlockNoteEditor` + `BlockNoteView` + `BlockActionRail`，真实 hover 后点击添加按钮）：`- Alpha` → `bulletListItem`、`1. Alpha` → `numberedListItem`、`- [ ] Alpha` → `checkListItem`（未勾选）、`> Alpha` → `quote`、`### Alpha` → `heading`（`level: 3` 保留）、ts 代码块 → `codeBlock`（`language: 'ts'` 保留）、普通段落 → `paragraph`。
  - 数据链路核验（真实编辑器插入 → `serializeBlockNoteDocument` 保存 → `parseBlockNoteDocument` 重新解析）：列表、编号、待办、引用、标题、代码块的空行都能原样还原，保存结果分别为 `- Alpha\n-`、`1. Alpha\n2.`、`- [ ] Alpha\n- [ ]`、`> Alpha\n\n>`、`## Alpha\n\n##`、```ts 空代码块。
- 已知限制或未处理的无关问题：
  - 空段落不会被直接序列化器写出（`blockMarkdownWithoutChildren` 对文本块返回空串后由 `serializeBlockList` 跳过），所以 Mermaid、数学块、图片等回退插入的空段落在保存后会消失。这与改动前「只添加一个空行」的行为一致，本次未扩大范围。
  - 大文档（≥16KB 或 ≥320 行）走快速解析器，裸 `-`、`2.`、`##` 会被解析成段落而不是空列表项/空标题（空待办 `- [ ]` 因 `preProcessEmptyChecklistItems` 注入零宽空格不受影响）。手动回车产生空列表项时同样如此，属既有问题，本次只记录不处理。
  - 本机无浏览器自动化环境，未在浏览器/Tauri 实机点击核验，以上界面核验以 jsdom 真实编辑器点击 + 保存/重载往返替代。
