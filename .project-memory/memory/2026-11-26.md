## 合并网址导入入口并缩小登录窗口

- 需求：网页直接导入与登录后导入复用一个菜单入口，登录窗口不再遮挡编辑器中的转换操作。
- 实现：统一通过「从网址导入」输入地址，再选择「直接导入」或「在登录窗口打开」。登录窗口默认 600×420 逻辑像素、可调整大小，初始位于编辑器所在屏幕工作区左上角；「转换当前网页」保留在主窗口中央。仅 HTTPS 地址可打开登录窗口，普通 HTTP(S) 导入与网页快照转换流程不变。
- 涉及模块：`useDocumentImport`、`TopBar`、`ConfirmDialog`、`document_import/webpage.rs`、中英文文案及使用指南。
- 验证：前端 3 个定向测试文件共 67 项通过，TypeScript 检查通过；Rust 编译与定向格式检查通过，文档导入定向测试 6 项通过、1 项因需要冻结转换器而跳过。浏览器以 800×600 视口和模拟桌面接口核验合并入口、转换面板居中和转换结果；333 个活跃代码文件最长 795 行。
- 限制：未实测原生窗口的多显示器定位或第三方登录网站。

## 接入 STranslate 使用的微信 OCR

- 需求：默认继续用 Tesseract，在 Windows x64 的「设置 → 组件」手动下载安装微信 OCR 后自动切换。
- 实现：从 NuGet 下载固定版本 `WeChatOcr 1.0.5` 及依赖，逐包校验长度及 SHA-256，只解包白名单文件，成功后才启用。识别在受超时约束的独立进程中运行，支持 PNG、JPEG 和 WebP；没有扩展名的网址还需核对图片签名。设置页切换时保留下载状态，桥接程序更新不重新下载运行时。
- 兼容：上游 .NET Framework 程序集预加载 `mmmojo_64.dll`，但 P/Invoke 仍查找 `mmmojo.dll`。Windows x64 安装把已校验的 64 位库同时放到这个名称；原包同名文件是 32 位。
- 验证：53 项前端导入测试、TypeScript 检查、27 项 Rust 导入测试及定向格式检查通过；真实 NuGet 安装与中文识别测试通过，并在隔离的 Windows 桌面实例中通过设置按钮完成下载。353 个活跃代码文件最长 795 行。
- 限制：FkeMark 不托管或随安装包分发上游运行时；NuGet 上游说明仅供学习使用。未发布组件、标签或应用安装包。

- 需求：降低动画期间的主线程和布局开销，清理取消、卸载及后台路径，遵循系统减少动态效果偏好。
- 实现：文件侧栏和分栏拖动按帧更新、正常松手后才持久化；侧栏开合不再逐帧改变编辑宽度。小地图只监听当前滚动容器，按帧更新指示器，复用同一行的悬浮预览，并取消迟到帧。
- 涉及模块：`useResizeDrag`、`useEditorSplitMode`、`Minimap`、`LinkGraphPanel`、`linkGraphSimulation`、`motion.css` 和中英文设置指南。图谱统一调度拖动、缩放、平移和模拟，隐藏窗口、加载替换画布及关闭时停止布局；演示与应用更新进度改为 `scaleX`。
- 验证：11 个定向 Vitest 文件、136 项测试和 `npx tsc --noEmit` 通过；本地 Chromium 通过页面操作核验拖动与持久化、分栏滚动、小地图悬浮清理和减少动态效果。348 个活跃代码文件最长 795 行。
- 限制：未采集生产 Tauri/WebView 的 FPS、长任务、CPU 或 GPU 对比数据，也未实测托盘行为。模糊、阴影、代码块测量与列表虚拟化保持原样，避免在没有性能录制证据时改变外观和交互。

## 优化文档标签、编辑模式与启动恢复

- 需求：消除重复打开和迟到切换，避免等待时闪回欢迎页或显示错误文档，返回标签时恢复视口，保持单个编辑器。
- 实现：`useDocumentOpen` 复用已开标签和在途读取，以导航版本阻止迟到激活；`useAppSession` 优先恢复活动文档，目录和其他标签不阻塞首个文档。搜索按目标标签和视图就绪定位；`useEditorViewport` 按标签与模式缓存滚动和源码选区，关闭标签时回收。
- 兼容：`EditorLayout` 保持 `BlockNoteView` 的 `editable` 属性稳定，避免属性变化重新挂载视图；实际可编辑状态由控制器更新，不发内容更新事件。设置背景使用 `inert`，关闭后恢复焦点并取消拖动；关闭标签释放保存版本和内容缓存。
- 验证：16 个定向 Vitest 文件、191 项测试通过，`npm run build -- --manifest` 通过。Chromium 中源码往返恢复正文、选区与 1895 像素滚动位置；生产前端构建预热后两轮各 50 次切换，编辑器 DOM 和外壳边界不变，回收后节点与监听器计数稳定在 849 和 422。窄窗口实测设置拖动中按 `Escape` 可关闭并恢复焦点和光标。
- 限制：首屏静态 JavaScript 为 13 个文件、978586 字节压缩大小；未验证单个低频面板独立拆分有显著收益，未引入新的加载边界。未采集原生 Tauri/WebView 冷启动、切换延迟或进程内存。
