## 统一主程序和文档转换组件更新弹窗

- 需求：参考 DBX 的更新窗口，把主程序与已安装的文档转换组件放到同一个更新中心。
- 实现：提供主程序、文档转换组件及更新日志三个标签页，显示更新数量、版本、发布说明和历史入口；支持按版本忽略、后台下载及更新全部。自动检查不下载，且只查询已安装的组件；首次安装仍在组件设置。主程序保留正式版和开发版通道及安装前保存、确认流程，组件更新不重启。
- 涉及模块：`useAppUpdates`、`useConverterUpdate`、`UpdateDialog`、更新中心样式、中英文资源及使用指南；Rust 组件检查复用既有 GitHub 发布源和平台归档校验。
- 验证：前端 83 个测试文件、660 项测试和生产构建通过；Rust 检查、定向格式检查通过，82 项测试通过、1 项依赖冻结转换器的测试未运行。浏览器加载生产页面并模拟 Tauri 接口，核验浅色弹窗、320×440 深色布局、长日志滚动、忽略恢复、批量下载及重启确认取消。342 个活跃代码文件最大 795 行。
- 限制：未真实下载或安装 GitHub 发布包，未验证跨窗口同时安装或回滚；浏览器仍报告欢迎页已有的两条 SVG 路径警告。

## 合并网址导入入口并缩小登录窗口

- 需求：网页直接导入与登录后导入复用一个菜单入口，登录窗口不再遮挡编辑器中的转换操作。
- 实现：统一通过「从网址导入」输入地址，再选择「直接导入」或「在登录窗口打开」。登录窗口默认 600×420 逻辑像素、可调整大小，初始位于编辑器所在屏幕工作区左上角；「转换当前网页」保留在主窗口中央。仅 HTTPS 地址可打开登录窗口，普通 HTTP(S) 导入与网页快照转换流程不变。
- 涉及模块：`useDocumentImport`、`TopBar`、`ConfirmDialog`、`document_import/webpage.rs`、中英文文案及使用指南。
- 验证：前端 3 个定向测试文件共 67 项通过，TypeScript 检查通过；Rust 编译与定向格式检查通过，文档导入定向测试 6 项通过、1 项因需要冻结转换器而跳过。浏览器以 800×600 视口和模拟桌面接口核验合并入口、转换面板居中和转换结果；333 个活跃代码文件最长 795 行。
- 限制：未实测原生窗口的多显示器定位或第三方登录网站。
